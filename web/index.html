markbridge

Edit the page; the markdown in Neovim changes within about half a second. Neovim stays the source of truth: if it changed first, your edit is dropped and the page reloads.

Blocks

  • Enter splits a block, or opens a new one at the end. Shift+Enter is a line break.
  • Tables: Tab / Enter move between cells, Tab in the last cell adds a row; buttons above the table add or remove rows and columns.
  • Code, mermaid and math: click to edit the source, Esc to render it.
  • Hover a block and use the ⋮⋮ handle to move, delete, convert it or insert a block below.
  • Paste or drop an image into a paragraph: it is saved next to the file and linked.
  • Click a block to move the Neovim cursor to it.
  • Frontmatter fields at the top are editable; lists there are read-only.

Good to know

  • Edits change the Neovim buffer. Save (Cmd/Ctrl+S) writes the file; the tab title shows a dot while there are unsaved changes.
  • An edited block is rewritten from the page; emphasis may normalise to *x* and **x**, tables are re-padded.
  • Auto / Light / Dark switches the page theme; the default comes from your Neovim config (theme).
  • ↻ reloads from Neovim and re-reads the file from disk (unless the buffer has unsaved edits).
