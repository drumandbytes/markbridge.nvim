1. USAGE                                                      *markbridge-usage*

                                                                   *:Markbridge*
:Markbridge [{sub}]
    {sub} is one of: >
        toggle   start, or stop when running (default)
        start    start for the current markdown buffer, or retarget to it
        stop     stop the server
        url      print the URL (it contains a per-session token)
        status   running or stopped
<
Lua API: `require('markbridge')`: `.start()`, `.stop()`, `.toggle()`, `.url()`,
`.is_running()`, `.setup({opts})`.

Health: `:checkhealth markbridge`

==============================================================================
2. CONFIGURATION                                             *markbridge-config*

>lua
    require('markbridge').setup {
      port = 0,            -- 0 = a free port; set one to keep the same URL
      open = true,         -- open the browser on start; or a function(url)
      follow = true,       -- retarget when you enter another markdown buffer
      scroll_sync = true,  -- scroll the page to the block under the cursor
      watch = true,        -- reload the buffer when the file changes on disk
      images_dir = 'assets', -- where pasted images go, relative to the file
    }
<

3. EDITING IN THE BROWSER                                   *markbridge-editing*

Editable: paragraphs, `#` headings, list items, task items, table cells, also
inside block quotes and lists. Read-only: code blocks, mermaid, display math,
HTML blocks, setext headings, frontmatter, and paragraphs holding reference
links, footnotes or autolinks.

Enter splits a block at the caret, or opens an empty block below when the caret
is at the end (paragraph, list item). In a table cell Enter and Tab move between
cells, and Tab in the last cell adds a row. Buttons above a focused table add and
remove rows and columns. Shift+Enter is a hard line break. Clicking a task
checkbox toggles it.

Code, mermaid and `$$` math blocks open their source in a text box on click.
Frontmatter `key: value` lines are fields. A pasted or dropped image is saved to
`images_dir` and linked. Shortcuts (Cmd or Ctrl): Alt+0..6 paragraph/heading,
Shift+7/8/9 numbered/bullet/task list, E inline code, K link, Shift+X strike. The
handle left of a top-level block moves, deletes, converts it, or inserts a block
below. Clicking a block moves the nvim cursor to it.

A bar at the top of the page has formatting buttons, undo and redo (nvim's
undo), refresh (also re-reads the file from disk) and a help panel (Cmd or
Ctrl+/).

An edited block is rewritten from the page; the rest of the file is untouched.
Soft-wrapped lines are kept, emphasis normalises to `*x*` / `**x**`, some
characters are escaped, and tables are re-padded (alignment is kept).

==============================================================================
4. SYNCING                                                      *markbridge-sync*

nvim wins: an edit made on a stale page is rejected and the page reloads. One
browser edit is one undo step. Browser edits do not save the buffer.

With `watch`, a change to the file on disk runs |:checktime|: an unmodified
buffer reloads, a modified one is never touched and the page shows a notice.

==============================================================================
5. SECURITY                                                *markbridge-security*

The server listens on 127.0.0.1 only. Requests need a random per-session token
(an `X-Token` header; the page URL carries it). It stops with `:Markbridge
stop`, when the previewed buffer is closed, or when Neovim exits.
